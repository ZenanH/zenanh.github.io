# Zenan Huo

Personal academic website with a password-protected Workbench for computer setup and software.

- `index.html`, `workbench.html`: site pages
- `assets/css/`: styles
- `assets/js/`: interactions and Workbench access
- `assets/images/`: favicon and university emblem
- `assets/data/`: encrypted Workbench content
- `scripts/`: local vault encryption utility
